Install & CLI Quick Start

Download SLSA-attested platform installers or launch the gateway directly from your terminal.

Launch Local Web GatewayStart the local HTTP/HTTPS proxy, MCP 2026-07-28 gateway, and embedded dashboard.
./outrider --web
Build Release Binary From SourceVerify SHA-256-pinned LiteRT-LM runtime libraries and compile the standalone release binary.
python3 scripts/install_native.py && cargo build --release -p proxyfor --bin outrider
Issue Operator Capability ReceiptMint an operator-signed Ed25519 capability receipt over RFC 8785 JCS canonical JSON.
./outrider receipt issue --subject <SESSION_UUID> --bundle-id outrider_session_evidence --max-calls 10 --expires-at-unix 1893456000
Verify Cryptographic AttestationVerify SLSA build provenance and PURL-tagged SPDX 2.3 SBOM attestations on release installers.
gh attestation verify Outrider-*.dmg --repo maceip/Outrider
